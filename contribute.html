Start with a conversation

If you're interested in contributing, you can email Jiayi Geng at ogeng@cs.cmu.edu about a new scientific discovery problem or additional scientific insights for an existing scientific discovery problem.

Ready to contribute?

We welcome domain experts interested in helping expand EurekaBench. You can propose a new scientific discovery problem or add scientific insights to an existing scientific discovery problem through the form below.

We'd like to collaborate with domain experts on new scientific discovery problems in the six domains currently included in EurekaBench and in new domains. These include problems from unpublished research and problems from recently published research that remain only partially solved.

The problem description should explain the scientific discovery problem and why it matters, identify the initial observations that challenge scientists' understanding of the world, and summarize the progress human scientists have made on the problem. In EurekaBench, these observations serve as the starting point for exploration. Agents run experiments to discover mechanisms that explain the observations, and we evaluate what scientific insights can be derived from those mechanisms.

Exploring a scientific discovery problem through different approaches can reveal different scientific insights. If you have explored a scientific discovery problem already included in EurekaBench through a different approach, we welcome additional scientific insights based on your research experience.

A scientific insight could explain an observation that is not yet understood, deepen our understanding of the scientific discovery problem, or suggest useful future directions to explore.

To contribute additional scientific insights, choose an existing scientific discovery problem from the list below. In the Scientific insights field, describe the additional scientific insights you expect to learn from a mechanism discovered by an AI agent.
